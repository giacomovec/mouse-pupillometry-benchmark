# GitHub Pages visibility boundary

The GitHub source repository and its GitHub Pages site are **public**. GitHub Pages could not be enabled while this personal-account repository was private under the current plan, so the repository was made public at the user's request after a full tracked-file audit. Public visibility exposes the repository source and history as well as the deployed HTML, JSON, and PNG assets. [GitHub documents Pages eligibility and visibility](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

The Pages workflow checks `dist/` after `npm ci`, lint, type checking, unit tests, packaged scientific-export consistency checks, and the build. Official Pages Actions then upload and deploy that verified artifact. The build includes 848 bounded, hash-linked mouse-eye PNGs and versioned JSON; it excludes raw video datasets, model checkpoints, protected confirmation material, and Allen predictions. The site remains visibly labeled a development benchmark with external evaluation unopened. `noindex` is a crawler request, not access control.

The project Pages path is `/mouse-pupillometry-benchmark/`. This repository uses official GitHub Pages Actions and does not maintain a `docs/` or `gh-pages` build folder. The workflow only deploys a build that passes all checks. The scientific freeze and Allen gate are controlled by the parent MouseFormer project, independently of website publication.
