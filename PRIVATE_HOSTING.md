# GitHub Pages visibility boundary

The GitHub source repository is private. GitHub's API currently rejects Pages setup for it: `Your current plan does not support GitHub Pages for this repository.` No Pages URL is live. If the account is upgraded to a plan that supports Pages from private repositories, the Pages site will be **public**. Repository privacy does not restrict access to the deployed HTML, JSON, or PNG assets. [GitHub documents public Pages from private repositories](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site); [private Pages access control is an Enterprise Cloud organization feature](https://docs.github.com/en/enterprise-cloud@latest/pages/getting-started-with-github-pages/changing-the-visibility-of-your-github-pages-site).

The Pages workflow checks `dist/` after `npm ci`, lint, type checking, unit tests, packaged scientific-export consistency checks, and the build. Official Pages artifact upload and deployment are paused until the repository variable `PAGES_DEPLOY_ENABLED=true`. The build includes 848 bounded, hash-linked mouse-eye PNGs and versioned JSON; it excludes raw video datasets, model checkpoints, protected confirmation material, and Allen predictions. The site remains visibly labeled a development benchmark with external evaluation unopened. `noindex` is a crawler request, not access control.

The project Pages path is `/mouse-pupillometry-benchmark/`. This repository uses official GitHub Pages Actions and does not maintain a `docs/` or `gh-pages` build folder. The workflow only deploys a build that passes all checks. The scientific freeze and Allen gate are controlled by the parent MouseFormer project, independently of website publication.
